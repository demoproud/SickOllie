# SICK OLLIE v4 — launch highlights

- **A connected Creative Library:** Templates, Prompts, Outfits and Scenes, organized with clear Homes and reusable Collections.
- **A proper Library Inspector:** large images, scoped browsing, keyboard ratings, contextual actions and copyable generation information.
- **Sharper previews:** aspect-preserving WebP up to 2048 px, with a compact 512 KiB budget and larger generation choices.
- **Live Theater review:** browse a run while it continues, with Creative Library stars or LoRA review states.
- **Collections that drive generation:** use LoRA groups in Loader and Wardrobe, Looks or Scene groups in Prompt Core.
- **Faster image reuse:** explicit Prompt Input selection, metadata copy/save controls and a recovered seed wired into Generation Core.
- **More controlled LoRA testing:** independent diffusion cycling, persistent trigger overrides, safe epoch-family rules and a live applied-LoRA monitor.
- **A clearer comparison loop:** Pin + Compare, Clear and Save to Library directly in Preview Core.
- **Outfit creation with room to grow:** a flexible Builder and optional local Outfit Forge beta for complete editable Look logs.
- **Portable content, clean installation:** selective .soslibrary packs and bulk curation, with no bundled starter content or old documentation.
