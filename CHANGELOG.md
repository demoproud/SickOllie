# Changelog

## 4.0.0 — 2026-09-06

Major release compared with the previous public **3.0.0** package.

- Introduces the four-area Creative Library, Home/Collection organization, Library Inspector and portable Library Packs.
- Adds unified Generate Previews, sharper preview storage and live Theater review.
- Connects LoRA and component Collections to the Studio nodes; improves queue-safe testing and numeric checkpoint runs.
- Adds explicit Prompt Input selection, seed input, persistent trigger overrides and live applied-LoRA reporting.
- Expands outfit assembly with Wardrobe and Looks plus local Outfit Forge beta.
- Simplifies Preview around Pin + Compare, Clear and Save to Library.
- Publishes a new v4 manual and removes all bundled starter payloads and historical documentation.

See [full patch notes](RELEASE_NOTES.md) or [launch highlights](LAUNCH_HIGHLIGHTS.md).

## 3.0.0 — previous public endpoint

The supplied public package established the Studio Core workflow, Classic compatibility, visual LoRA/Recipe libraries and integrated organizers. Existing useful features are taught in the manual without presenting them all as new in v4.
